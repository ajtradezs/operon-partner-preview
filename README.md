# Operon partner preview

Clickable preview adapted from the published 14 October 2026 demonstration. All data and security screens are simulated. No production app code, credentials or real partner addresses are included.

Use `aidan.demo@example.test`, `johan.demo@example.test`, or `roelof.demo@example.test` and the demonstration code `123456`. Any syntactically valid demo email works. These are demonstration identities, not accounts or access controls.

Feedback is saved only in the visitor's browser. Export it as JSON from **My feedback** and send it to Aidan. Reloading resets the synthetic work; resetting demonstration work preserves saved feedback.

The real app uses separate email/password accounts and mandatory authenticator-app MFA on the server laptop. This static GitHub Pages site does not connect to that database.
